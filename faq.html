Frequently Asked Questions

The Pulse suite for DaVinci Resolve, explained — updated August 29, 2026

Everything people ask about Pulse Edit, Pulse Studio and Pulse Color — one page, straight answers. Missing something? Write to support@pulseedit.com.

What is Pulse Edit?

Pulse Edit is an automatic beat-synced video editor for DaVinci Resolve. It detects the beats of your music with AI and cuts your clips frame-exact onto them, exporting an OTIO timeline that DaVinci Resolve — including the free edition — imports by drag-and-drop.

Does Pulse Edit detect individual notes?

No. Pulse Edit tracks the musical beat — the steady pulse you would tap your foot to — and cuts on that. It does not mark individual note onsets. If you need a marker on every note attack, for example each note of a solo piano piece, the beat grid is the wrong tool for that and Pulse Edit will not do what you need.

What is Pulse Studio?

Pulse Studio does the same beat-synced edit directly inside DaVinci Resolve Studio through the official scripting API: no export, no import. It works with the clips already in your Media Pool, places beat markers, inserts the audio track, and can generate speed ramps with Optical Flow (beta). It requires Resolve Studio, the paid edition.

What is Pulse Color?

Pulse Color is an OFX color plugin for DaVinci Resolve (Free and Studio) that converts camera log footage to a finished film look in one node, with stackable emulations of on-set optical filters: Black Pro-Mist, Glimmerglass, halation, anamorphic streak and more.

Do I need one license or three?

One. A single Pulse license — €13/month or €130/year, VAT included — activates Pulse Edit, Pulse Studio and Pulse Color with the same key.

Which tool do I need for my edition of DaVinci Resolve?

Resolve Free: Pulse Edit (Resolve Free has no scripting API, so Pulse Edit's OTIO workflow is the way in) and Pulse Color. Resolve Studio: Pulse Studio for the most direct workflow, plus Pulse Edit and Pulse Color if you want them. All from the same license.

Does Pulse work on both macOS and Windows?

Yes. macOS builds are signed and notarized (Apple Silicon; Pulse Color also Intel). Windows 10/11 installers are provided for all three tools.

Which DaVinci Resolve versions are supported?

DaVinci Resolve 18.5 or later — both Free and Studio. Pulse Studio specifically requires the Studio edition because only Studio exposes the scripting API.

How does the OTIO import into DaVinci Resolve Free work?

Pulse Edit writes an OpenTimelineIO (.otio) file next to your project. In Resolve you drag it into the Media Pool (or File → Import → Timeline) and the edited timeline appears with all cuts in place. No scripting API is involved, which is why it works on Resolve Free.

What setup does Pulse Studio need in Resolve?

One preference, once: Preferences → System → General → "External scripting using" = Local, then restart Resolve Studio. Pulse Studio finds the Resolve installation automatically on macOS and Windows.

Why don't I see beat markers or ramps from Pulse Edit?

Beat markers, audio insertion and speed ramps are Pulse Studio features — they need the scripting API, which only Resolve Studio has. Pulse Edit delivers the same cut timeline via OTIO, without markers.

Is Pulse Studio stable?

The Pulse Studio workflow launched on 29 August 2026 and is in beta testing. The core path (detect, cut, markers, audio) is solid; speed ramps are the newest part and flagged beta in the app. Anything odd: support@pulseedit.com.

Can Pulse edit weddings in chronological order?

Yes. Both Pulse Edit and Pulse Studio can read each clip's real recording time and assemble the day as it happened — getting ready, ceremony, party — while still cutting on the beat. Two cameras interleave correctly when their clocks are in sync.
