What lands in Final Cut Pro

  • The cuts, on the beat, with the in-point of every clip.
  • The music, trimmed the way you trimmed it.
  • Beat markers — beat markers on the music clip, on the exact frame.
  • A cut list in JSON, if you would rather read the edit than open it.

What stays in DaVinci Resolve Studio

  • Speed ramps and animated zooms. They are built through the Resolve Studio scripting API and live only in Pulse Studio.
  • The AI mood edit. Same reason.
  • Transitions. The export carries cuts, not effects.

How to import it

  1. Open Final Cut Pro Open the library you want the project in.
  2. File → Import → XML… Skip it if Final Cut already opened the file for you.
  3. Choose the library Final Cut creates an event with the project, the clips and the music.
  4. Clips show as missing? Select them → File → Relink Files, and point at your video folder.
  5. Check the cuts They land on the beat, and the beat markers sit on the music clip.

Why it says beta

The file is written to spec — the FCPXML is validated against Apple's published DTD on every export. What we have not done yet is open it inside Final Cut Pro ourselves — not once. We do not own the licence, so the file is validated against the format, not against the application that reads it. Until that changes the feature carries a BETA label: in the app, on this page, and in the menu where you pick it. We would rather tell you than have you find out.

If something does not import cleanly, write to support@pulseedit.com and send the file — that is exactly what takes it out of beta.
