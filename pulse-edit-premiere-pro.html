What lands in Premiere Pro

  • The cuts, on the beat, with the in-point of every clip.
  • The music, trimmed the way you trimmed it.
  • Beat markers — sequence markers on every beat, on the exact frame.
  • A cut list in JSON, if you would rather read the edit than open it.

What stays in DaVinci Resolve Studio

  • Speed ramps and animated zooms. They are built through the Resolve Studio scripting API and live only in Pulse Studio.
  • The AI mood edit. Same reason.
  • Transitions. The export carries cuts, not effects.

How to import it

  1. Open Premiere Pro Open or create the project first.
  2. File → Import… Or Cmd/Ctrl + I, and pick the .xml Pulse Edit wrote.
  3. Open the sequence Premiere creates a bin with the sequence, the clips and the music.
  4. Clips say «Media Offline»? Right-click them in the Project panel → Link Media, and point at your video folder.
  5. Check the cuts They land on the beat, and every beat carries a sequence marker.

Why it says beta

The file is written to spec — the XML follows the FCP7 interchange format Premiere imports. What we have not done yet is open it inside Premiere Pro ourselves — not once. We do not own the licence, so the file is validated against the format, not against the application that reads it. Until that changes the feature carries a BETA label: in the app, on this page, and in the menu where you pick it. We would rather tell you than have you find out.

If something does not import cleanly, write to support@pulseedit.com and send the file — that is exactly what takes it out of beta.
